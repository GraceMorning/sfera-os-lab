# Сфера ОС Лаб

Экспериментальная системная лаборатория вокруг языка «Сфера».

Цель проекта — сделать воспроизводимый путь от русскоязычного исходного
кода до программы, которая запускается без готовой операционной системы.
Первый рубеж — загрузочный образ для QEMU с выводом через последовательный
порт.

Публичный репозиторий проекта:
https://github.com/GraceMorning/sfera-os-lab

## Принцип проекта

Вся пользовательская поверхность проекта русскоязычная:

- исходники;
- имена каталогов и файлов;
- команды лаборатории;
- сообщения сборки;
- документация;
- примеры программ;
- имена будущих библиотек и устройств.

Названия внешних форматов и инструментов остаются только на границах
совместимости: QEMU, LLVM, C ABI, регистры процессора и команды GNU.

## Текущий статус

Готов первый загрузочный каркас:

1. 16-битный загрузчик помещается в один загрузочный сектор;
2. загрузчик настраивает последовательный порт;
3. через порт выводится сообщение на русском языке;
4. образ можно проверить в QEMU;
5. рядом лежит исходник будущего входа ядра на Сфере.

Важно: текущая версия ещё не компилирует исходник Сферы в bare-metal-образ.
Маленький загрузчик на ассемблере является временной границей до тех пор,
пока компилятор «Сферы» не получит отдельную цель без операционной системы.

## Быстрый запуск

Нужны команды:

- `as`;
- `ld`;
- `objcopy`;
- `qemu-system-x86_64`.

Из корня проекта:

```bash
cd сфера-ос-лаборатория
./сборка/проверить_окружение.sh
./сборка/собрать.sh
./сборка/проверить_запуск.sh
./сборка/запустить.sh
```

При запуске QEMU вывод появится в текущем терминале через последовательный
порт. Созданный образ находится в `образе/сфера-ос-лаборатория.img`.

`проверить_запуск.sh` запускает QEMU в фоне, ждёт русское сообщение
загрузчика в последовательном порту и завершает виртуальную машину после
успешной проверки.

## Структура

```text
сфера-ос-лаборатория/
├── загрузчик/                 граница между железом и будущим ядром
├── ядро/                      исходники на Сфере
├── сборка/                    русскоязычные команды сборки и запуска
├── документация/              технические контракты
├── планы/                     последовательность развития
└── образе/                    результаты сборки
```

## Следующий рубеж

Следующим этапом нужно добавить в компилятор «Сферы» отдельную цель
`без_операционной_системы_x86`, определить соглашение входа ядра и заменить
временный ассемблерный вывод на вызов русскоязычной функции из исходника
Сферы.

## Публикация

Лаборатория развивается отдельным репозиторием. Улучшения самого компилятора
и стандартной библиотеки будут возвращаться в исходную «Сферу» отдельными
Pull Request. Правила разделения и черновик первого предложения автору лежат
в `документация/публикация_на_github.md` и
`документация/первое_предложение_автору.md`.
