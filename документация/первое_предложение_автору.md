# Первое предложение автору «Сферы»

## Заголовок задачи

Добавить воспроизводимую цель `без_операционной_системы_x86`

## Текст предложения

Мы развиваем отдельную лабораторию «Сфера ОС Лаб» вокруг языка «Сфера».
Лаборатория проверяет, можно ли использовать язык для системного
программирования без готовой операционной системы.

Сейчас у нас есть минимальный загрузочный образ x86, который:

- собирается в один сектор размером 512 байт;
- запускается в QEMU;
- выводит русское сообщение через последовательный порт.

Следующий шаг — поддержать в компиляторе отдельную цель
`без_операционной_системы_x86` с явным соглашением входа ядра.

Предлагаемый минимальный контракт:

- известная точка входа `начало`;
- документированное состояние регистров;
- передаваемый указатель стека;
- отсутствие обязательной зависимости от системных вызовов;
- отдельная библиотека функций, доступных без операционной системы;
- проверка результата в QEMU.

На первом этапе мы не предлагаем добавлять полноценную операционную систему
или менять обычный режим компиляции. Цель должна быть изолированной и
включаться явно.

Реализацию загрузчика и лабораторных примеров мы готовы поддерживать в
отдельном репозитории, а изменения компилятора и стандартной библиотеки
отправлять небольшими Pull Request.
