# Публикация и совместная работа на GitHub

## Выбранная модель

«Сфера ОС Лаб» развивается как самостоятельный проект, а исходный
репозиторий языка «Сфера» остаётся upstream-проектом.

Это означает:

- загрузчик, лабораторное ядро, QEMU-сценарии, драйверы и учебные материалы
  живут в репозитории «Сфера ОС Лаб»;
- изменения компилятора «Сферы», синтаксиса, семантики и стандартной библиотеки
  сначала оформляются как отдельная задача;
- готовое изменение компилятора отправляется автору исходной Сферы через
  Pull Request;
- лаборатория может временно использовать экспериментальную ветку компилятора,
  но не должна незаметно менять его поведение внутри своего репозитория.

## Как будет выглядеть публикация

1. Подключить GitHub к рабочему окружению.
2. Создать отдельный публичный репозиторий с названием `sfera-os-lab` или
   согласованным русскоязычным вариантом.
3. Перенести содержимое этой лаборатории в корень нового репозитория.
4. Добавить ссылку на исходный репозиторий «Сферы» как на основу компилятора.
5. Открыть первую задачу в исходной Сфере с предложением bare-metal-цели.
6. Реализацию компиляторной части отправлять отдельными Pull Request.

Пароли, токены и ключи в переписку не передаются. Для публикации используется
безопасное подключение GitHub к рабочему окружению.

## Границы репозиториев

| Что меняется | Где живёт |
| --- | --- |
| Загрузочный образ и запуск QEMU | «Сфера ОС Лаб» |
| Ядро и драйверы на Сфере | «Сфера ОС Лаб» |
| Скрипты проверки железа | «Сфера ОС Лаб» |
| Новый тип цели компилятора | Pull Request в исходную Сферу |
| Исправление парсера или семантики | Pull Request в исходную Сферу |
| Bare-metal-стандартная библиотека | Сначала предложение автору, затем согласованное место |
| Учебные примеры | «Сфера ОС Лаб», с обратными ссылками в документацию языка |

## Правило имён

В обоих проектах пользовательские имена, сообщения, документация и примеры
остаются русскоязычными. Английские названия допускаются только для внешних
протоколов, ABI, форматов и инструментов, с которыми нужно сохранить
совместимость.
